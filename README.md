# MOTION WAVE DJ

摄像头体感 3D DJ 节奏游戏 —— 身体就是乐器。

**[在线试玩](https://shixingya.github.io/motion-wave-dj/)** · 无需安装，打开浏览器即可开玩 · License: MIT

## 项目简介

MOTION WAVE DJ 是一款纯网页端的体感节奏游戏：摄像头捕捉你的动作，用挥手、下蹲来打节拍、演奏乐器；Three.js 实时渲染的霓虹夜店舞台随节拍律动，所有音乐均由 Web Audio 程序化合成。不需要手柄，不需要下载，举起手臂就能开始。

## 功能亮点

- **完全 3D 夜店舞台（Three.js）**：12x12 发光地砖、巨型 LED 动画屏、8 台摇头灯光束、镭射扫射、彩带与打击粒子爆发、镜面地板 + Bloom 辉光，全部程序化生成，零外部素材
- **同屏双人**：单人或双人同场竞技，画面左侧为玩家 1（青色）、右侧为玩家 2（品红），DJ 模式下独立计分
- **画中画骨架**：右下角小窗实时叠加显示摄像头画面与 33 关节彩色骨架，可点击收起/展开
- **三种模式**：
  - **DJ 节奏**：跟拍完成左臂/右臂/双手/下蹲目标动作，冲击连击高分，90 秒结算
  - **乐器创作**：身体即乐器——左臂弹钢琴、右手扫吉他、下蹲换和弦、双手举打镲，还支持 8 秒录制与回放
  - **自由舞台**：无评分畅玩，任何动作都有音效与灯光回应
- **Web Audio 纯合成零素材**：底鼓、军鼓、镲、低音炮、钢琴、吉他、和弦全部程序化合成，背景曲按曲风（HOUSE/EDM/FUNK）与 BPM 实时生成，无任何音频文件
- **键盘降级全家可玩**：没有摄像头、摄像头被拒或设备不支持时，自动切换键盘/触屏按钮模式，爷爷奶奶小孩都能上手

## 玩法速览

| 动作 | DJ 节奏 / 自由舞台 | 乐器创作 |
| --- | --- | --- |
| 左臂高举 | 左打击（底鼓） | 弹钢琴（手臂高度决定音高） |
| 右臂高举 | 右打击（军鼓） | 右手快速下压 = 吉他扫弦 |
| 双手高举 | 重拍（镲片） | 打镲 |
| 下蹲 | 低音炮 | 和弦（C-F-G-Am 轮换 + 底鼓） |

| K | 右打击 | 吉他扫弦 |
| L | 下蹲 | 和弦 |
| I | 双手高举 | 镲 |

## 本地运行

本项目为纯前端零构建应用，但摄像头（getUserMedia）要求页面通过 http(s) 访问，直接双击打开本地文件无法启用摄像头。任选一种静态服务器：

```bash
# 方式一：Python
python -m http.server 8091

# 方式二：Node.js
npx serve .
```

然后用浏览器打开 `http://localhost:8091`（端口以你启动的服务为准），授权摄像头即可开始。

环境要求：

- Chrome 或 Edge 最新版（需支持 WebGL 与 getUserMedia）
- 摄像头一枚（可选：无摄像头时自动进入键盘模式）
- 首次加载需联网下载姿态识别模型（约 5MB，之后有浏览器缓存）

## 技术栈

- **three@0.160.0**：3D 夜店舞台渲染（importmap + ESM，含 UnrealBloom 后期）
- **@mediapipe/tasks-vision**：PoseLandmarker 姿态识别（lite 模型，GPU 优先自动降级 CPU）
- **Web Audio API**：全部音效与背景曲程序化合成（lookahead 精确排程）
- **纯前端零构建**：原生 ES Modules，无打包器、无框架、无构建步骤

## 项目结构

```
motion-wave-dj/
├── index.html          # 入口页面（importmap / HUD / 菜单 / 引导弹窗）
├── css/style.css       # 全部样式（霓虹夜店风）
└── js/
    ├── game.js         # 主控制器：状态机、三模式玩法、判定计分
    ├── stage3d.js      # Three.js 3D 舞台：地砖/LED 屏/灯光/粒子/骨架人偶
    ├── audio.js        # Web Audio 引擎：乐器合成 + 程序生成背景曲
    ├── pose.js         # MediaPipe 姿态感知：摄像头 + 动作判定辅助
    └── ui.js           # UI 层：菜单/HUD/画中画骨架/键盘降级/引导
```
