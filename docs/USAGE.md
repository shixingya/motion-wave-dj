# MOTION WAVE DJ 使用手册

摄像头体感 3D DJ 节奏游戏 —— 用身体打节拍，灯光为你而闪。

## 1. 快速开始（5 步）

1. **打开页面**：用 Chrome 或 Edge 最新版访问 <https://shixingya.github.io/motion-wave-dj/>（本地运行见第 2 节）
2. **授权摄像头**：浏览器弹出摄像头权限请求时点击"允许"（详见第 3 节；没有摄像头可直接跳到第 3 步，用键盘玩）
3. **选择人数**：在主菜单点击"单人"或"双人"
4. **选择模式**：点击三张模式卡之一——"DJ 节奏模式"、"乐器创作模式"或"自由舞台模式"
5. **确认动作说明开始游玩**：首次进入每种模式会弹出动作说明弹窗，点击"我知道了，开始！"即进入游戏

提示：首次进入 DJ 节奏模式即可上手——屏幕中央会提前显示下一个目标动作（左臂高举 / 右臂高举 / 双手高举 / 下蹲），在节拍点上完成动作即可得分。

## 2. 环境要求

| 项目 | 要求 |
| --- | --- |
| 浏览器 | Chrome 或 Edge 最新版（桌面端体验最佳，需支持 WebGL 与 getUserMedia） |
| 摄像头 | 可选。有摄像头体验完整体感；没有时自动进入键盘/触屏降级模式 |
| 网络 | 首次加载需联网下载姿态识别模型（约 5MB），之后走浏览器缓存 |
| 硬件 | 主流笔记本或台式机（集成显卡即可，低配设备会自动降级画质） |
| 页面协议 | 必须通过 http(s) 访问；本地双击打开文件（file://）时浏览器会禁用摄像头 |

本地运行（任选其一启动静态服务器，然后在浏览器打开对应地址）：

```bash
# 方式一：Python
python -m http.server 8091
# 打开 http://localhost:8091

# 方式二：Node.js
npx serve .
# 按命令行输出的地址打开
```

## 3. 摄像头授权指引

1. 首次进入游戏并选择模式后，浏览器地址栏附近会弹出权限请求，选择"**允许**"即可
2. 若误点了"阻止"：
   - Chrome / Edge：点击地址栏左侧的摄像头图标（或锁形图标）→ 将"摄像头"改为"允许"→ 按提示刷新页面
   - 也可进入浏览器 设置 → 隐私和安全 → 网站设置 → 摄像头，找到本站改为允许
3. 授权成功后，右下角会出现画中画小窗（摄像头画面 + 彩色骨架线）；点击小窗可收起或展开
4. 画面中骨架颜色：青色为玩家 1（画面左侧）、品红色为玩家 2（画面右侧）

没有摄像头或不想授权？完全不影响——选择模式后游戏会自动进入键盘模式，照样得分与结算。

## 4. 三种模式玩法说明

### 4.1 DJ 节奏模式（跟拍打点，冲击高分）

- 每局 90 秒，背景曲随机 BPM（112~128）与曲风（HOUSE / EDM / FUNK 轮换）
- 屏幕中央提前显示下一个目标动作，四选一：**左臂高举 / 右臂高举 / 双手高举 / 下蹲**（按 8 拍一循环轮换，下蹲每 8 拍出现 1 次）
- 在节拍点上完成目标动作：

| 判定 | 时机 | 得分 |
| --- | --- | --- |
| PERFECT | 目标拍前后 150ms 内 | 100 |
| GOOD | 目标拍前后 300ms 内 | 50 |
| MISS | 300ms 内未完成 | 断连击 |

- **连击加成**：连击数达到 10 以上后每次得分 ×1.5，尽量别断连
- 90 秒结束后进入结算屏：每人得分、最高连击、评级（S / A / B / C）与历史最高分
- 做错动作（非目标动作）不会被扣分，但也不会得分；下蹲动作要完整蹲到位

### 4.2 乐器创作模式（身体即乐器）

| 你的动作 | 演奏效果 |
| --- | --- |
| 左臂上下挥动 | 弹钢琴：手臂越高音越高（C 大调五声音阶，怎么弹都好听） |
| 右手快速下压 | 吉他扫弦：右手抬得越高，扫出的音越高 |
| 双手高举 | 打镲 |
| 下蹲 | 换和弦：每蹲一次依次切换 C、F、G、Am，并叠加一脚底鼓 |

录制与回放（一人乐队玩法）：

1. 按 **R** 开始录制，屏幕提示"开始录制（8 秒）"，尽情演奏
2. 8 秒后自动结束；录制中途再按一次 **R** 立即结束并开始回放
3. 回放会原样重演你刚才的演奏，且可以叠加——连续按 R 让多段演奏同时响起

### 4.3 自由舞台模式（无评分畅玩）

- 没有目标、没有判定、没有分数：左臂 = 底鼓、右臂 = 军鼓、双手 = 镲、下蹲 = 低音炮
- 背景曲 110 BPM 固定律动，任何动作都有灯光爆闪与鼓励语回应
- 适合热身、给长辈小孩演示，或单纯跟着音乐摇摆

## 5. 双人模式站位建议

1. **并排站位**：两人左右并排站在摄像头前，各自完整入画，中间留出少量间隔
2. **距离**：距摄像头约 **1.5~3 米**，保证两人从头到腰（下蹲时到脚踝）都在画面内
3. **左右关系**：站画面**左边**的是玩家 1（青色骨架），站画面**右边**的是玩家 2（品红色骨架）；结算与 HUD 按此对应
4. **光线**：面光充足、避免逆光（不要背对窗户），识别会更稳
5. **动作幅度**：手臂高举要高过肩膀再往上，下蹲要蹲到位（髋部明显下沉），避免半途收回造成误判
6. **键盘提示**：键盘无法区分玩家——双人模式下按 J/K/L/I 会同时判定两名玩家，公平竞技请尽量使用体感

## 6. 键盘映射表

| 按键 | DJ 节奏 / 自由舞台 | 乐器创作 |
| --- | --- | --- |
| J | 左打击（底鼓） | 弹钢琴（随机音） |
| K | 右打击（军鼓） | 吉他扫弦 |
| L | 下蹲（低音炮） | 切换和弦 |
| I | 双手高举（镲） | 打镲 |
| R | — | 开始 8 秒录制 / 再按结束并回放 |
| ESC | 返回菜单 | 返回菜单 |
| D | 开关调试面板 | 开关调试面板 |

说明：

- 无摄像头时游戏画面底部会显示 J / K / L 三个触屏按钮，点按等效按键盘（移动端友好）
- 创作模式键位与 DJ 模式不同：J/K/L/I 分别对应钢琴/吉他/和弦/镲
- 按 ESC 可随时返回主菜单（会停止当前曲目并清空录制状态）

## 7. 常见问题排查

### 看不到骨架（画中画里没有人形线条）

- 确认右下角小窗已展开（点击小窗可收起/展开）
- 确保整个人在画面内、光线充足、避免逆光；离摄像头 1.5~3 米最佳
- 首次进入时模型约需 5MB 下载，网络慢请耐心等待加载提示消失
- 画面很暗时识别会变差：打开房间灯或换到面光位置
- 每种模式的首次引导弹窗确认后才会开始检测，确认没有卡在弹窗

### 画面卡（掉帧 / 不流畅）

- 关闭其他占用摄像头/显卡的程序（视频会议、其他网页摄像头页签）
- 游戏自带自适应降级：持续卡顿会自动降低阴影、粒子与辉光特效，属于正常保护
- 按 D 打开调试面板查看帧率：前一个数字是感知帧率（单人约 35、双人约 25 属正常），后一个是渲染帧率（目标 60）
- 笔记本请接电源并选择高性能模式；浏览器开启硬件加速（设置 → 系统 → 使用硬件加速）

### 没声音

- 点击过模式卡即已激活音频引擎；若整局无声，按 ESC 回菜单重新进入模式
- 检查系统音量与浏览器标签页是否被静音（标签页右键 → 取消静音）
- 蓝牙耳机偶发延迟或断连，可换有线耳机或扬声器
- DJ 模式 HUD 中曲目信息若显示"无音频"，说明音序器启动失败，重进即可

### 摄像头被拒 / 无法启动

- 提示"权限被拒绝"：地址栏摄像头图标 → 改为允许 → 刷新页面（详见第 3 节）
- 提示"未检测到摄像头"：接入摄像头，或直接用键盘模式（J / K / L / I）
- 提示"摄像头被其他程序占用"：关闭正在使用摄像头的其他应用（会议软件、其他页签）后重试
- 通过 file:// 双击打开本地文件时摄像头会被浏览器禁用：请改用第 2 节的静态服务器方式访问
- 以上都不行时游戏会自动进入键盘模式，玩法不受影响

## 8. 隐私说明

- **视频数据不上传**：摄像头画面只在你的浏览器本地处理，姿态识别全程在设备端完成，不存在任何上传、存储或第三方共享
- 本项目没有服务器后端，没有账号体系；页面加载的仅是公开 CDN 上的开源库与识别模型
- 本地唯一持久化数据是 DJ 模式历史最高分（浏览器 localStorage 键 `mwdj_best_v1`），清除浏览器数据即随之删除
- 关闭页面或拔掉摄像头授权，一切画面数据立即消失
